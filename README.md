# Deep Dublicator 🕵️‍♂️

**Deep Dublicator** — это мощный кроссплатформенный инструмент на Python (PySide6) для наведения порядка на компьютере. Приложение объединяет в себе продвинутый поиск дубликатов, визуальный анализатор дискового пространства и очистку системного мусора.

## ✨ Ключевые возможности

### 🔍 Поиск дубликатов
*   **Точное совпадение** по хешу (SHA-256) с быстрой предварительной проверкой.
*   **Похожие фотографии** (Perceptual Hash) и **видео** (по первому кадру).
*   **Аудиофайлы** по тегам (ID3: исполнитель, название).
*   **Поиск ссылок** (символьные и жесткие ссылки на конкретный файл).
*   **Поиск мусора** (файлы, забитые нулями) и **поиск по имени**.
*   **Безопасность**: режим «Симуляция» (Dry-run), журнал операций (Undo-лог), интеграция с **VirusTotal** для проверки хешей на вирусы.
*   **Умные действия**: удаление (в корзину/навсегда), замена на симлинки/хардлинки, перемещение в бэкап, переименование.
*   **Экспорт**: сохранение отчетов в CSV, HTML, TXT и генерация готовых BAT-скриптов.

### 📊 Анализ дискового пространства
*   **Ленивое сканирование** (Lazy-loading) — программа не зависает даже на огромных дисках.
*   **Интерактивный Treemap** (карта диска) для визуализации тяжелых папок.
*   **Дерево файлов** с сортировкой по размеру, проценту и количеству файлов.
*   **Топ-файлы** (самые тяжелые объекты на диске).
*   **Хитмап** распределения места по типам файлов (расширениям).
*   **Контекстные действия**: открыть папку, удалить, найти дубликаты прямо из дерева.

### 🐷 Большие файлы (Space Hogs)
*   Быстрый поиск файлов размером более 100 МБ, 500 МБ или 1 ГБ.
*   Фильтрация «забытых» файлов (которые не изменялись более 1 или 2 лет).

### 🧹 Очистка мусора (Junk Cleaner)
*   Поиск и удаление временных файлов `%TEMP%`.
*   Очистка папок разработчика: `__pycache__`, `node_modules`.
*   Удаление системных миниатюр `Thumbs.db`.

### 🎨 Интерфейс и UX
*   Современный **сайдбар** (боковая панель) вместо классических вкладок.
*   **9 тем оформления**: Windows 11, Windows 10/7, Windows Vista (Aero), KDE Plasma, Proton, темная и светлые темы.
*   Встроенный предпросмотр: HEIC, PDF, видео, изображения, текст.
*   Сворачиваемая панель настроек, чтобы не отвлекать от результатов.
*   Системный трей с уведомлениями о завершении сканирования.
*   Сохранение геометрии окна, ширины колонок и выбранной темы.


## 🛠 Установка и запуск

**Требования:** Python 3.10 или выше.

### 1. Клонирование репозитория
```bash
git https://github.com/Astarta-ada/deep-dublicator.git
cd deep-dublicator
```

### 2. Создание виртуального окружения
Это изолирует зависимости проекта от вашей системы.

```bash
# Windows / macOS / Linux
python -m venv .venv
```
### 3. Активация виртуального окружения
Выберите команду в зависимости от вашей операционной системы и терминала:

🪟 Windows (Командная строка / CMD):

```cmd
.venv\Scripts\activate.bat
```
🪟 Windows (PowerShell):

```powershell

.venv\Scripts\Activate.ps1
```
(Если PowerShell выдает ошибку политики выполнения, выполните: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser и попробуйте снова).

🍏 macOS / 🐧 Linux (Bash / Zsh):

```bash
source .venv/bin/activate
```
### 4. Установка зависимостей
После активации окружения (в начале строки терминала появится (.venv)), установите библиотеки:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```
### 5. Запуск приложения
```bash
python main.py
```
💻 Запуск в режиме CLI (без интерфейса)
Приложение поддерживает работу из командной строки для автоматизации:

```bash
python main.py --cli /path/to/scan --report report.html
```
