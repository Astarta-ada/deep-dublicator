# Deep Dublicator 🕵️‍♂️

**Deep Dublicator** — это мощное кроссплатформенное десктопное приложение на Python (PySide6) для поиска дубликатов файлов, умного анализа дискового пространства и наведения порядка в файловой системе.

## ✨ Ключевые возможности

*   **Умный поиск дубликатов**:
    *   Точное совпадение по хешу (SHA-256).
    *   Похожие фотографии (Perceptual Hash).
    *   Похожие видео (по первому кадру).
    *   Аудиофайлы по тегам (ID3).
    *   Поиск по имени файла.
    *   Поиск "мусорных" файлов (забитых нулями).
    *   Поиск символьных и жестких ссылок на файл.
*   **Безопасное управление файлами**:
    *   Удаление (в корзину или безвозвратно).
    *   Режим "Симуляция" (Dry-run) — показывает, что будет удалено, но не трогает файлы.
    *   Замена на символьные (Symlink) или жесткие (Hardlink) ссылки.
    *   Перемещение в папку-бэкап с сохранением структуры.
    *   Массовое переименование копий.
    *   Журнал операций (история действий).
*   **Анализ дискового пространства**:
    *   Ленивое сканирование (без зависаний интерфейса).
    *   Визуализация в виде карты диска (Treemap).
    *   Топ-100 самых тяжелых файлов.
    *   Распределение по типам файлов.
    *   Навигация "Назад/Вперед" и хлебные крошки.
*   **Интерфейс**:
    *   Поддержка 9 тем оформления (Windows 11, Windows 7, Vista, KDE Plasma, Proton, темная и др.).
    *   Встроенный предпросмотр файлов (HEIC, PDF, изображения, видео, текст).
    *   Горячие клавиши и Drag-and-Drop папок.

## 🛠 Установка и запуск

**Требования:** Python 3.10 или выше.

### 1. Клонирование репозитория
```bash
git https://github.com/Valllium/deep-dublicator.git
cd deep-dublicator
```

### 2. Создание виртуального окружения
Это изолирует зависимости проекта от вашей системы.

```bash
# Windows / macOS / Linux
python -m venv .venv
```
### 3. Активация виртуального окружения
Выберите команду в зависимости от вашей операционной системы и терминала:

🪟 Windows (Командная строка / CMD):

```cmd
.venv\Scripts\activate.bat
```
🪟 Windows (PowerShell):

```powershell

.venv\Scripts\Activate.ps1
```
(Если PowerShell выдает ошибку политики выполнения, выполните: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser и попробуйте снова).

🍏 macOS / 🐧 Linux (Bash / Zsh):

```bash
source .venv/bin/activate
```
### 4. Установка зависимостей
После активации окружения (в начале строки терминала появится (.venv)), установите библиотеки:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```
### 5. Запуск приложения
```bash
python main.py
```
💻 Запуск в режиме CLI (без интерфейса)
Приложение поддерживает работу из командной строки для автоматизации:

```bash
python main.py --cli /path/to/scan --report report.html
```
