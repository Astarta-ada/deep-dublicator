## [0.7.3] - 2026-11-09

### Исправлено (Fixed)
- **CLI**: Исправлена сигнатура `progress_cb` (теперь принимает 4 аргумента: `stage, done, total, filename`), что предотвращало `TypeError` при реальном запуске.
- **CLI**: Флаг `--include-empty` теперь корректно сбрасывает `min_size` в 0, позволяя находить пустые файлы.
- **File Ops**: Исправлена передача метаданных в `log_action` для `move_to_backup` и `rename_duplicates`. Undo-лог (История операций) теперь корректно отменяет эти действия.
- **File Ops**: `_safe_create_link` переписан на безопасную схему с `.bak_link`. Теперь при сбое переименования дубликат не теряется, а возвращается на место.
- **Workers**: `HogsScanner` больше не падает при передаче `None` в качестве корневой папки. Добавлены сигналы прогресса и отмены.
- **Workers**: `FolderScannerWorker` восстановлен внешний `except Exception`, чтобы UI не зависал при системных ошибках сканирования.
- **Duplicate Finder**: Исправлен баг с отступами в `_total_size` (теперь возвращает корректную сумму размеров, а не только первого файла).
- **Disk Analysis**: Удален дублирующий класс `PercentDelegate`, оставлена кастомная зеленая отрисовка прогресс-бара.
- **Тесты**: Устранены кроссплатформенные падения тестов (моки `Path.stat`, `Path.resolve`, drag&drop с реальными `tmp_path`, `skipif` для Windows-only симлинков).
- **CI**: Исправлена генерация версии на macOS (удален heredoc из `$()`), сборка артефактов через `ditto` для сохранения прав `.app`.
